# Security Policy

## Scope

This is an analytics portfolio project. It has no authentication, no user accounts, no network calls to third-party services, and it collects nothing. The dataset in `database/zomato.db` is entirely synthetic, generated by `database/build_zomato_db.py` — there is no real user, customer, or payment data anywhere in this repository, and there never should be.

The one component that accepts untrusted input is the **SQL playground** on the Streamlit dashboard, which lets a visitor run a query against the read-only database. It is sandboxed in `streamlit_app/common.py`:

- the SQLite connection is opened read-only at the OS level (`mode=ro`), so writes fail even if attempted
- `PRAGMA query_only = ON` blocks writes to temp objects as well
- only a single `SELECT` / `WITH` statement is permitted
- results are capped at 500 rows and queries are aborted after 5 seconds

If you find a way past any of those, that is a genuine vulnerability and I would like to know.

## Reporting a vulnerability

**Please do not open a public issue for a security problem.**

Use GitHub's private reporting instead:

1. Go to the [Security tab](../../security/advisories/new) of this repository
2. Open a draft security advisory

That routes it privately to the maintainer. If private advisories are unavailable to you, reach out through the contact details on https://github.com/shreyanshverma7.

Please include what you did, what happened, and what you expected — a reproducing query or request is ideal.

## What to expect

This is a personal project maintained in spare time, so there is no formal SLA. I will acknowledge reports as soon as I reasonably can, and credit you in the fix unless you would rather stay anonymous.

## Supported versions

Only the latest commit on `main` is supported. There are no maintained release branches.

## Out of scope

- Anything about the synthetic data being unrealistic — that is a documented property, not a defect. See the README's *Reading these numbers honestly* section.
- Availability of the hosted demo on Streamlit Community Cloud, which is a free tier and may sleep or rate-limit.
